# AI 워크플로우

Biniverse 개발에서 Claude Code를 활용하는 방식을 기록한다.

## 주요 사용 패턴

### 게임 기능 개발
- 씬 추가, 적 패턴 설계, 물리 로직 구현 등 Pixi.js 기반 작업

### 모노레포 관리
- 패키지 간 의존성 설정
- Turborepo 태스크 구성

### 코드 리뷰
- `/code-review` 슬래시 커맨드로 변경사항 검토

### 문서화
- `/update-docs` 슬래시 커맨드로 아키텍처 문서 동기화

## 협업 규칙

- 응답 언어: 한국어
- 커밋 메시지: 한국어
- 코드 주석: 한국어
- 변수/함수명: 영어 (코드 표준)

## 주의사항

- `any` 타입 사용 금지
- 복잡한 추상화 지양
- 컴포넌트 분리 및 재사용 우선
